# VIDYACHAKRA repository rules

1. This is a visual frontend prototype.
2. Do not add backend services or databases.
3. Preserve the established VIDYACHAKRA design language.
4. Do not create generic admin-dashboard layouts.
5. Do not fill pages with rows of identical statistic cards.
6. Use RAG colours only for compliance status.
7. Every RAG indicator must include an icon and text, not colour alone.
8. Use realistic interface copy, never lorem ipsum.
9. Every button must perform a simulated action, open a drawer, change local state, or show a toast.
10. Use fictional university and college names.
11. Display one subtle “Illustrative Prototype” indicator globally; do not repeat mock-data labels.
12. Do not use official government emblems, university logos, or seals unless supplied.
13. Only run basic build, configured lint, and browser sanity checks.
14. Do not create automated tests unless specifically requested.
15. Universities cannot create course names.
16. University course selectors must use active HEC Course Master records.
17. Course offerings always belong to AcademicDeliveryUnits.
18. Do not add seat, intake, vacancy, capacity or student-strength reporting.
19. Keep course offerings focused on official course and delivery-unit details.
20. Do not remove the existing academic calendar governance workflow.
